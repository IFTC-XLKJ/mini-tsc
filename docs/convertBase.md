# convertBase 函数文档

## 概述

`convertBase` 是 mini-tsc 提供的全局函数，用于在任意进制（2-36）之间转换数字字符串，支持小数部分的转换。

## 函数签名

```typescript
function convertBase(value: string, fromBase: number, toBase: number): string;
```

## 参数

| 参数 | 类型 | 描述 |
|------|------|------|
| `value` | `string` | 要转换的数字字符串 |
| `fromBase` | `number` | 源进制（2-36） |
| `toBase` | `number` | 目标进制（2-36） |

## 返回值

| 类型 | 描述 |
|------|------|
| `string` | 转换后的数字字符串 |

## 支持的进制范围

- 最小进制：2（二进制）
- 最大进制：36（使用 0-9 和 A-Z 作为数字字符）

## 示例

### 整数转换

```typescript
// 十进制转二进制
convertBase("10", 10, 2);      // "1010"
convertBase("255", 10, 2);     // "11111111"

// 十六进制转十进制
convertBase("FF", 16, 10);     // "255"
convertBase("1A", 16, 10);     // "26"

// 十进制转十六进制
convertBase("255", 10, 16);    // "FF"
convertBase("26", 10, 16);     // "1A"

// 二进制转八进制
convertBase("1010", 2, 8);     // "12"
convertBase("11111111", 2, 8); // "377"

// Base 36 转换
convertBase("ZZ", 36, 10);     // "1295"
convertBase("1295", 10, 36);   // "ZZ"
```

### 小数转换

```typescript
// 十进制小数转二进制
convertBase("3.14", 10, 2);    // "11.00100011110101110000101000111101"

// 二进制小数转十六进制
convertBase("1010.11", 2, 16); // "A.C"

// 十六进制小数转十进制
convertBase("A.C", 16, 10);    // "10.75"
```

### 符号处理

```typescript
// 负数
convertBase("-10", 10, 2);     // "-1010"
convertBase("-FF", 16, 10);    // "-255"

// 正号（可选）
convertBase("+FF", 16, 10);    // "255"
```

### 边界情况

```typescript
// 零
convertBase("0", 10, 2);       // "0"

// 无效输入返回空字符串
convertBase("abc", 10, 2);     // ""（包含非数字字符）
convertBase("10", 1, 2);       // ""（进制超出范围）
convertBase("10", 10, 37);     // ""（进制超出范围）
```

## 实现细节

### 输入解析

1. 处理符号（`+` 或 `-`）
2. 解析整数部分：逐字符转换为数值
3. 解析小数部分：使用权重累加

### 输出转换

1. 整数部分：使用除基取余法
2. 小数部分：使用乘基取整法（最多 32 位精度）

### 精度说明

- 整数部分：使用 `long long` 类型，支持大数值
- 小数部分：最多 32 位精度，超出部分截断

## 错误处理

以下情况返回空字符串 `""`：

1. 进制超出 2-36 范围
2. 输入字符串包含无效字符
3. 输入字符串为空

## 性能

- 时间复杂度：O(n)，其中 n 是输入字符串长度
- 空间复杂度：O(1)，使用固定大小的缓冲区

## 相关函数

- `parseInt(str, radix?)` - 解析字符串并返回整数（仅支持整数部分）
- `parseFloat(str)` - 解析字符串并返回浮点数（仅支持十进制）
- `Number.prototype.toString(radix)` - 将数字转换为指定进制的字符串（仅支持整数部分）

## 使用场景

1. **数据格式转换**：在不同进制表示之间转换数据
2. **用户输入处理**：处理用户输入的进制转换请求
3. **网络协议**：处理不同进制表示的网络数据
4. **密码学**：在不同进制之间转换加密数据
5. **调试工具**：显示内存地址、二进制数据等

## 注意事项

1. 输入字符串中的字母不区分大小写（`FF` 和 `ff` 等效）
2. 小数部分的精度有限（最多 32 位）
3. 对于非常大的整数，可能会丢失精度（超过 `long long` 范围）
4. 返回的字符串始终使用大写字母（`A-Z`）
